# Bharat Paints — Instagram Posts

Drop folder for the Bharat Paints Instagram account (@bharatpaints_1976).

## How to use

1. Open the **`new`** folder and tap **Add file → Upload files**.
2. Pick photos or videos from your phone gallery, then tap **Commit changes**.
3. Every alternate day, Claude takes the oldest file from `new`, writes the caption and sends it to Gaurav for approval.
4. After approval it is posted to Instagram and the file is moved to **`posted`**.

## Tips

- **Name the file** with what it shows, e.g. `seepage-roof-sector13.jpg` or `gio-paints-rice-mill.mp4`. Claude uses the name to write a better caption.
- **Videos:** keep them short (15–60 seconds) and under about 25 MB when uploading from a phone. Vertical (9:16) videos look best as Reels.
- **Photos:** JPG or PNG. Several photos with the same starting name (e.g. `kitchen-1.jpg`, `kitchen-2.jpg`) are posted together as one carousel.
- Files in this repository are public. Do not upload anything private.

## Folders

| Folder | What goes there |
|---|---|
| `new/` | Photos and videos waiting to be posted |
| `posted/` | Files already posted (moved here automatically) |
